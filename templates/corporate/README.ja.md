# Corporate テーマ

企業サイト向けの落ち着いたレイアウト。明るい背景にネイビーの配色、ヒーロー + お知らせ一覧構成、ヘッダー / フッターナビ付き。

## カスタマイズ

`/admin/sites/<siteId>/theme` で設定:

- **タグライン** — ヒーロー内、サイト名の上に表示される短いフレーズ
- **プライマリカラー**
- **角丸**
- **トップストーリーのスラッグ** — ヒーローとお知らせ一覧の間に公開済み投稿を 1 件フィーチャー
- **ロゴ画像 URL**
- **ヘッダーナビ** — ラベル + URL のペア
- **フッターリンク** — ラベル + URL のペア
- **フッター注記** — 住所 / 会社情報 / 追加の注意書き
