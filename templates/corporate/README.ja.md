# {{siteName}}

コーポレート / 企業サイト向けテーマ：明るい背景にネイビーの配色、ヒーロー + ニュースのレイアウト、ヘッダー + フッターナビゲーション付き。

## カスタマイズ

`/admin/sites/<siteId>/theme` から設定できます：

- タグライン（ヒーロー内のサイト名上に表示される短いキャッチコピー）
- ヘッダーナビゲーション（ラベルと URL のペア）
- フッターリンク + 欄外テキスト（住所 / 会社情報 / 注意書きなど）
- メインカラー、角丸の大きさ

## はじめに

```bash
npm install
npm run sandbox
```
