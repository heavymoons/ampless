# {{siteName}}

Docs テーマ：サイドバー主導のドキュメントレイアウトです。サイドバーは通常のリンクと**タグ駆動セクション**を組み合わせています — サイドバーのナビゲーションフィールドに `tag:guide` のような URL を入力すると、「guide」タグが付いた公開済み投稿の一覧として自動展開されます。執筆者はコンテンツをタグで整理するだけで、ナビゲーションに自動的に反映させることができます。

## カスタマイズ

`/admin/sites/<siteId>/theme` から設定できます：

- **サイドバーナビゲーション** — 各行は `ラベル` と `URL` のペアです。URL には以下を指定できます：
  - パス（`/getting-started`）
  - 外部 URL（`https://...`）
  - タグ参照（`tag:tutorials`）→ 見出し + タグ付き投稿の一覧としてレンダリング
- ヘッダーナビゲーション（トップレベルのリンク）
- コードフォント（system mono / JetBrains Mono など）
- メインカラー、角丸の大きさ

## 執筆のヒント

投稿に `guide` タグを付け（投稿エディターで設定）、サイドバーに URL `tag:guide` の行を追加するだけです。投稿を公開するたびにリンクを手動で編集しなくても、サイドバーに自動的に表示されます。

## はじめに

```bash
npm install
npm run sandbox
```
