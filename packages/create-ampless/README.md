# create-ampless

CLI scaffolding tool for ampless projects.

> ⚠️ **Early development** — not yet usable.

## Usage

```bash
npx create-ampless@latest
```

The CLI will guide you through:

1. Project name
2. Theme selection
3. Plugin selection

Then run:

```bash
cd my-project
npm install
npm run dev
```

## Requirements

- Node.js >= 20
